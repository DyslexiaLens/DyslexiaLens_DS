Short introductions and Meeting Expectation <Fill before the mentoring session>				
1	Proyek DyslexiaLens membangun sistem early screening disleksia berbasis analisis citra tulisan tangan menggunakan AI.			
2	Sistem menerima input gambar tulisan tangan dan menghasilkan label klasifikasi (disleksia / tidak) beserta tingkat keparahan..			
3	Sistem juga dilengkapi fitur terjemahan tulisan tangan (handwriting-to-text) yang memanfaatkan API atau model eksternal yg ada.			
4	Ekspektasi sesi ini: mendapatkan arahan dan feedback terkait progres proyek secara keseluruhan dari sudut pandang manajemen.
